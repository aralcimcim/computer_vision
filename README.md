# Computer Vision

My computer vision coursework, covering image processing, camera calibration, segmentation, object detection and tracking, depth estimation, 3D reconstruction, and diffusion-based image generation.

## Contents

| Folder | Topics |
|---|---|
| [As_1](As_1/) | Gaussian and Laplacian pyramids, image reconstruction, camera calibration, noise, and PSNR |
| [As_2](As_2/) | Feature extraction with PyTorch and retinal vessel segmentation using U-Net and attention variants |
| [As_3](As_3/) | Motion anomaly detection, Farneback optical flow, RX anomaly detection, Faster R-CNN, and Deep SORT tracking |
| [As_4](As_4/) | Monocular depth estimation with MiDaS, exercises on VGGT-based 3D reconstruction, and text-to-image generation with Stable Diffusion |

The repository also includes introductory notebooks on Python, NumPy, computer vision, and deep learning.

## Highlights

- Building and reconstructing image pyramids.
- Investigating how image resolution and noise affect camera calibration.
- Comparing U-Net segmentation models with different attention mechanisms.
- Combining object detection and tracking for video analysis.
- Exploring pretrained depth-estimation and image-generation models.

## Tools

Python, Jupyter, OpenCV, NumPy, Matplotlib, scikit-image, scikit-learn, PyTorch, torchvision, Deep SORT, and Hugging Face Diffusers.
